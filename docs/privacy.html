净装隐私政策

版本：1.0 生效日期：2026 年 10 月 16 日 更新日期：2026 年 10 月 16 日 适用产品：净装 Windows 客户端

我们深知个人信息对您的重要性，并会尽全力保护其安全可靠。我们致力于维持您对我们的信任，恪守以下原则保护您的个人信息：权责一致原则、目的明确原则、选择同意原则、最小必要原则、确保安全原则、主体参与原则、公开透明原则。

同时，我们郑重承诺：本产品不设置账号体系，不收集、不存储、不上传您的个人信息，亦不含任何形式的统计分析或广告组件。

  1. 本政策的适用范围
  2. 我们如何收集和使用您的信息

  8. 本政策的更新
  9. 如何联系我们

一、本政策的适用范围

1.1 本政策由《净装》开发者（以下简称「我们」）制定并发布，适用于我们提供的净装桌面客户端软件及其后续版本（以下简称「本产品」）。

1.2 本产品是一款在您的本地设备上独立运行的 Windows 桌面工具，核心功能为：依据您输入的关键词，检索并核验软件官方下载来源，对下载的安装包进行完整性校验与安全提示。

1.3 本产品不提供在线账号服务，您无需注册、登录或提交任何身份信息即可使用全部功能。

1.4 请您在使用本产品前仔细阅读并充分理解本政策。若您开始使用本产品，即表示您已充分理解并同意本政策的全部内容。

二、我们如何收集和使用您的信息

2.1 我们不会收集您的个人信息。本产品未集成任何形式的遥测、埋点、使用行为统计或广告 SDK，亦不设置开发者服务端，相关数据不会以任何方式回传给我们。

2.2 本产品在运行过程中产生的数据及其用途如下：

2.2.1 本机存储的数据

以下数据仅保存于您的本地设备（路径为 %APPDATA%\jingzhuang\），不会上传：

  1. 配置信息：界面主题、下载目录等偏好设置；
  2. 名单数据：白名单、黑名单、风险软件清单及其自定义修改；
  3. AI 服务凭据：由您自行填写的第三方 AI 服务接口地址、模型名称与 API Key；
  4. 使用记录：您检索过的软件名称与时间，仅用于界面展示最近检索项，可由您在设置中随时清空。

2.2.2 因功能需要而向外发起的网络请求

仅在您主动使用相应功能时，本产品才会向外部发起必要的网络请求。具体情形如下：

功能模块接收方传输内容触发条件与说明
AI 辅助检索 由您自行配置的第三方 AI 服务提供商 您输入的检索词；为核验来源真实性而抓取的候选官方页面文本内容 仅当您主动配置 AI 服务并触发 AI 检索时发送。该请求不包含任何个人身份信息
官方索引检索 微软公司（Windows 程序包管理器公开索引） 您输入的检索词 为本产品默认启用的检索方式，可在设置中关闭
云端安全检测
（可选）		 VirusTotal 安装包文件的 SHA‑256 摘要值 仅当您自行配置接口密钥后启用。仅传输文件的哈希摘要，不上传文件本身
安装包下载 软件的官方下载服务器 常规的 HTTP 下载请求 为完成您所请求的下载行为所必需，与使用浏览器下载安装包的技术过程一致

2.3 除上述情形外，本产品不会将您的任何信息用于其他目的，亦不会将其用于广告推送、用户画像或商业推广。

2.4 关于数据出境：上述第三方服务提供商可能位于中华人民共和国境外。若您选择使用境外服务商，相关数据传输行为由该服务商依据其自身隐私政策处理，请您在使用前审阅其条款并自行判断。您可以通过不配置相关服务的方式，完全避免此类数据传输。

2.5 关于生成式 AI 内容的反馈与举报：本产品中的生成式 AI 仅用于辅助判定软件来源并生成安装建议，不用于生成图像、音视频等内容。若您认为 AI 返回的内容存在错误、误导或不适宜之处，可通过本产品「设置 → 关于 → 反馈与举报」，或本政策第九条所列渠道告知我们，我们将及时核实并处理。

三、我们如何共享、转让、公开披露您的信息

3.1 我们不会共享您的个人信息，因为本产品不收集您的个人信息，亦不存在开发者服务端可供数据汇集。

3.2 我们不会将您的信息转让给任何第三方。

3.3 我们不会公开披露您的信息。

3.4 本政策第 2.2.2 条所述的网络请求，系由您的本地设备直接发起并直接送达相应接收方，我们不参与、不经手、不留存该过程中的任何数据。

四、我们如何存储与保护您的信息

4.1 存储位置与期限

  1. 本政策第 2.2.1 条所列数据全部存储于您的本地设备，存储期限由您自行决定，您可以随时删除；
  2. 安装包的默认保存位置为系统的「下载」文件夹；商店版本默认为应用自身的私有目录，您亦可在设置中指定为其他目录；
  3. 本产品卸载后，本地配置与名单数据默认予以保留，以便您重新安装后继续使用；如您希望一并清除，可在卸载前于设置中删除，或手动删除 %APPDATA%\jingzhuang\ 目录。

4.2 安全措施

  1. 本产品的网络请求均通过 HTTPS 加密通道传输；
  2. 本产品运行时不申请管理员权限；若所下载的安装包需要提权，将由 Windows 用户账户控制机制向您独立征求确认；
  3. 商店版本不申请 broadFileSystemAccess 等宽泛文件访问权限，默认仅写入应用自身私有目录；若您主动将下载目录指定为其他位置，Windows 将通过系统文件选择器向您确认，授权范围仅限您所选定的文件夹；
  4. 您所填写的 AI 服务密钥仅保存在本地设备，用于您自身的接口调用。请妥善保管您的设备与密钥，避免在公用设备上留存凭据。

五、您的权利

基于本产品不收集个人信息的设计，您对本产品所涉数据享有完全的控制权：

  1. 查阅与更正：您可在「设置」中查看并修改全部配置项、名单数据与使用记录；
  2. 删除：您可随时在设置中清空使用记录，或直接删除 %APPDATA%\jingzhuang\ 目录以清除全部本地数据；
  3. 撤回同意：您可随时关闭官方索引检索、清除 AI 服务配置或移除云端检测密钥，从而完全停止相应的数据传输；
  4. 注销：本产品不设账号体系，故不涉及账号注销事项。

六、未成年人保护

6.1 本产品为软件来源查询与安装包校验工具，不面向儿童设计，亦不主动收集任何与年龄相关的信息。

6.2 若您为未满 14 周岁的未成年人，请在您的父母或其他监护人的指导下阅读本政策，并在其同意后使用本产品。

6.3 我们不会在明知的情况下收集未成年人的个人信息。若监护人发现相关情形，可通过本政策第九条所述方式与我们联系，我们将及时处理。

七、第三方服务与组件说明

  1. Geek Uninstaller：本产品集成了该第三方卸载工具，其著作权归原作者所有，其运行行为受其自身许可协议与隐私政策约束；
  2. 第三方 AI 服务：由您自行选择并配置，服务条款与数据处理规则以该服务商的公开政策为准，请您在配置前予以审阅；
  3. 微软 Windows 程序包管理器索引与 VirusTotal：分别为微软公司与 VirusTotal 提供的公开服务，其数据处理规则以各自公开政策为准。

八、本政策的更新

8.1 我们可能会适时对本政策进行修订。未经您明确同意，我们不会削减您依据本政策所应享有的权利。

8.2 对于重大变更，我们将通过本产品版本更新说明或本页面显著位置予以提示。本政策的任何更新均会同步发布于本页面，并更新页首的版本号与更新日期。

8.3 若您在政策更新后继续使用本产品，即视为您接受修订后的政策；若您不同意，请停止使用本产品。

九、如何联系我们

若您对本政策或个人信息保护相关事宜有任何疑问、意见或投诉，可通过以下方式与我们联系：

  1. 问题反馈：github.com/sqdcz/jingzhuang/issues
  2. 政策全文：sqdcz.github.io/jingzhuang/privacy.html

我们将在收到您的反馈后尽快予以答复。
