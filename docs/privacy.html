隐私政策

生效日期：2026 年 10 月 16 日

净装（以下简称「本软件」）是一款完全本地运行的 Windows 桌面工具，用于帮助用户查找软件的官方下载地址、校验安装包安全性并给出安装建议。

一、我们收集什么

什么都不收集。
  • 没有任何遥测、行为统计或使用分析
  • 没有任何广告 SDK
  • 没有开发者自己的服务器，也不会把你的任何数据发给我们（开发者）
  • 不需要注册账号，不索取邮箱或手机号

二、什么时候会有数据发给第三方

只有在你自己主动配置的情况下，才会有数据离开本机：

功能发送给谁发送什么说明
AI 智能查找 你在设置里填写的 AI 服务商（如 DeepSeek / 硅基流动 / 智谱等） 你输入的软件名或功能描述、程序抓取到的候选官网页面内容 不配置就不发送。发送对象由你决定，数据受该服务商的隐私政策约束
Winget 官方索引 微软（winget 源） 你输入的查询词 微软官方包管理器的公开索引。可在设置里关闭
VirusTotal 云查杀（可选） VirusTotal 下载文件的 SHA256 哈希值 只发哈希，不上传文件本身。不配置 Key 就不查询
下载安装包 软件的官方下载服务器 普通的 HTTP 下载请求 与你用浏览器下载安装包完全相同

三、数据存在哪里

  • 设置与名单：保存在本机 %APPDATA%\jingzhuang\（白/黑名单、AI 配置、主题偏好），不会上传
  • API Key：保存在本机上述目录，仅用于你自己的 AI 请求
  • 下载的安装包：默认保存到系统的「下载」文件夹；商店版（MSIX）默认保存到应用自己的私有目录，你也可以在设置里改成任意目录
  • 历史记录：仅记录软件名与时间，保存在本机

四、权限说明

  • 本软件运行时不需要管理员权限（下载的安装包若需要提权，由 Windows UAC 自行弹窗）
  • 商店版（MSIX）不申请 broadFileSystemAccess 等受限能力：默认只写入应用私有目录，避免触达用户其他文件
  • 若你主动把下载目录改到别处，Windows 会通过系统文件选择器向你确认，授权范围仅限你选中的那个文件夹
  • 内置 Geek Uninstaller 用于卸载软件，其权限需求由 Geek 自身决定

五、儿童隐私

本软件不针对 13 岁以下儿童，也不收集任何年龄相关信息。

六、第三方内容

  • 内置 Geek Uninstaller（免费软件，版权归其作者所有）
  • AI 服务由用户自行选择并承担相应服务条款

七、变更

若本政策有实质变更，会在本页面与 GitHub 仓库同步更新。
